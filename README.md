# 我要自学网前端

基于 Vue3、Vite、Vue Router、Pinia、Axios、Element Plus 的前端基础架构。

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 目录

```text
src
├── api              # Axios 请求封装与接口模块
├── components       # 公共组件
├── layouts          # 页面布局
├── router           # 路由与权限守卫
├── stores           # Pinia 状态管理
├── styles           # 全局样式
└── views            # 页面视图
```
